# Troubleshooting

재발 가능하고 원인 파악이 어려운 문제의 해결법을 기록합니다.

## 작성 기준

- 증상으로 검색할 수 있는 제목을 사용합니다.
- 원인, 해결 명령 또는 변경, 정상화 확인 방법을 함께 기록합니다.
- 다시 발생하지 않도록 적용한 예방책이 있다면 남깁니다.
- 한 번성 로컬 실수나 Git 이력만으로 충분한 문제는 추가하지 않습니다.
- 비밀값, 운영 데이터, 개인 로컬 경로는 기록하지 않습니다.

새 문서는 [`../templates/troubleshooting.md`](../templates/troubleshooting.md)를 복사해 작성하고 아래 목록에 링크합니다.
